# “埃斯顿杯”创新型赛道一：项目上下文与硬约束

最后核对：2026-10-02

依据文件：`/opt/vendor_documents/参赛资料/比赛任务说明.pdf`

## 参赛任务

本项目用于第三届“埃斯顿杯”大学生机器人大赛，参赛方向为：

- 创新型赛道一：智能抓取应用
- 机器人平台：ESTUN S3-60 Eco 协作机器人
- 核心目标：在限定时间内，自主识别并抓取料框中随机摆放、无序堆叠的物体，将其放到指定区域

赛题覆盖的能力包括：

- 任务 A：不同空间位置和姿态下的 2D/3D 目标检测，检测框 IoU 不低于 0.75
- 任务 B：透明料框内四角和中心共五个位置的定点抓取、规划、执行与放置
- 任务 C：大小透明料框之间的无序抓取和搬运
- 任务 D：未见过物体的抓取和搬运，用于考察泛化能力
- 任务 F：按照预先指定顺序抓取和搬运
- 物体可能包含透明、柔性、较重、细小物体，并会在赛前临时加入未知物体

## 现场标定约束

以下是本项目必须遵守的比赛现场约束。第一条来自比赛准备的实际条件，不是赛题 PDF 的原文：

1. 比赛现场不能预先知道相机相对机械臂的安装位置，因此必须现场重新进行眼在手外标定。
2. 标定采样姿态必须根据现场 marker 的实际可见性在线获得，不能预设一个依赖相机视野的固定 `Calibration Exit` 姿态。
3. `Ready` 或 `Gripper Ready` 可以是机器人基座坐标系下固定的关节姿态；它们不依赖相机安装位置。但从最后一个标定姿态到 Ready 的路径必须根据当前关节状态和现场环境在线规划。
4. 完成标定后，可利用求得的 `base_link -> camera` 外参建立相机碰撞模型；桌面、料框及其他障碍物也必须进入 MoveIt PlanningScene，之后才能执行较大幅度的姿态翻转。
5. 标定板拆除、夹爪安装或工具更换后，必须切换到正确的工具碰撞模型和 TCP，再开始抓取流程。

## 标定后到抓取前的正确流程

1. 根据现场视野人工或半自动采集足够分散的 marker 姿态。
2. 求解并检查手眼标定残差及留一法稳定性。
3. 保存求解完成时的真实关节状态，不要求最后一个采样姿态等于某个预设姿态。
4. 拆除标定板、安装夹爪，并确认 TCP、负载和碰撞模型正确。
5. 根据新外参和现场感知结果更新相机、桌面、透明料框等碰撞体。
6. 从当前关节状态在线规划到若干机器人侧候选安全姿态，选择可达、无碰撞且代价最小的方案；候选可以包含 Real Ready 和 Gripper Ready，但不要求相机仍能看到 marker。
7. 按本项目已完成真机验证的 0.10 rad blended 分段方法回到抓取准备姿态，然后进入目标检测、预抓取、抓取和放置流程。

## 对现有 Ready 程序的边界认识

历史上的 `real_ready_blended_execute_demo` 采用每个关节最大约 `0.1 rad` 的逻辑分段。此前真机成功案例的最大总关节变化约为 `0.522 rad`，只验证了 6 个逻辑分段，并没有证明它能从任意远距离标定姿态安全返回 Ready。

本项目已经在真机验证的标准关节运动方法是：按照最大单关节变化每 0.10 rad 生成一个逻辑关键点，对每一小段分别进行 MoveIt 规划、速度、加速度和终点检查，再把 Current 与全部逻辑关键点组合成一次连续 RobotMove。所有后续较大关节运动都必须复用这一方法，不得直接发送 MoveIt 生成的大量原始轨迹点，也不得仅通过放宽最大角度限制绕过分段检查。

## 当前开发优先级

1. 实现独立的“标定后重构姿态”节点：读取当前关节状态，在线规划到多个候选 Ready，并仅在 plan-only 检查通过后允许执行。
2. 将相机、桌面和料框自动或半自动加入 PlanningScene。
3. 把已经真机验证的 `0.1 rad` blended 分段方法抽成公共运动模块，供回 Ready、抓取和放置流程统一调用。
4. 在安全完成姿态重构后，再把手眼标定、通用目标感知、抓取策略和顺序任务串成比赛状态机。
